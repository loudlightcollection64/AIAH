# Event lifecycle

How a So Many Angels event runs. Items marked **(today)** are confirmed current practice;
**(wanted)** is what Matt wants; **(unknown)** still needs confirming with Matt.

## 1. Plan
- [today] Pick a city, find a venue, set a capacity, recruit volunteers and sponsors, recruit families through partner organisations
- [today] A hand-built event page per event on the website (Elementor)
- [wanted] Enter location, date, capacity and volunteers once; everything else is set up from that

## 2. Register
- [today] Families fill in the Fluent Forms "SMA Session Signup" form (form 5) at /likeness-release/
- [today] The form asks for child's first name, age, diagnosis, costume/theme, flash sensitivity, guardian name, email, phone, address, event (dropdown), likeness release, social and media permissions, typed signature
- [today] The event dropdown is typed in by hand; past events are not removed automatically
- [wanted] Automatic acknowledgement, duplicate detection, a view of who still needs scheduling

## 3. Approve
- [wanted] Matt reviews and approves each registration before the family can book
- [unknown] Whether approval happens today, and how

## 4. Schedule
- [wanted] Approved family gets a link, picks a time (sessions are about 10 minutes), gets a confirmation
- [unknown] How families get their appointment time today
- [today] FluentBooking is the booking tool: the live /select-a-time/ page embeds a FluentBooking calendar (public page, 14 Oct 2026). Simply Schedule Appointments is installed but unpaid and unused in the flow.

## 5. Remind
- [wanted] Reminders 14, 7, 3 and 1 days before, with safeguards against duplicate or wrong sends
- [unknown] Which emails are automatic today and which are sent by hand

## 6. Volunteers
- [today] Fluent Forms "SMA Volunteer Application" (form 9) at /volunteer: name, contact, role, T-shirt size, event
- [wanted] Portfolio upload, location choice, approve step, reusable volunteer profiles

## 7. Event day, editing, printing, reveal, follow-up
- [today] Photographers submit RAW files within ~24 hours; editors finish in ~3 days; prints at 16×24, 300 ppi via H&H Color Lab
- [today] Canvases delivered by post (up to 60 days) or presented at a reveal event
- [wanted] Check-in, production tracking, print tracking, automated thank-yous. Future phase, not for the hackathon.
